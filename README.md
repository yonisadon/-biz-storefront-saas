# -biz-storefront-saas
A Hebrew-first SaaS platform for small business storefronts. One shared application serves all businesses; each business has its own PostgreSQL database within one Railway PostgreSQL service. A central registry resolves public slugs and secure seller-management tokens. Row-level security remains defense in depth.

See [`SYSTEM_SPEC.md`](./SYSTEM_SPEC.md) for the product and architecture specification, provisioning flow, environment variables, and migration procedure.
